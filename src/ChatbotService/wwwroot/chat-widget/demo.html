💻 Integrazione nel tuo sito

📋 Modalità di utilizzo

BFF Routing: Per integrazione in DistributedOrderSystem tramite GatewayBff

Direct Service: Per progetti esterni con comunicazione diretta al ChatbotService

<!-- Includi il widget nel tuo HTML --> <script src="/api/chatbot/widget/chat-widget.min.js"></script> <script> // Configurazione per BFF routing window.chatWidgetConfig = { useBffRouting: true, bffBaseUrl: '/api/gateway/chat', theme: 'light', primaryColor: '#4299e1', position: 'bottom-right', autoOpen: false, botName: 'Assistente AI', welcomeMessage: 'Ciao! Come posso aiutarti oggi?' }; // Il widget si inizializza automaticamente </script>

🔧 Inizializzazione programmatica

// Per controllo avanzato const widget = new DistributedChatWidget({ useBffRouting: false, // Direct mode chatbotServiceUrl: 'https://your-service.com/api/chat', theme: 'dark', primaryColor: '#9f7aea', jwtToken: 'your-auth-token' }); // Controlli programmatici widget.show(); widget.hide(); widget.updateConfig({ theme: 'light' });
