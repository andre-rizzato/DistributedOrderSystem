💻 Integration into your site

📋 Usage modes

BFF Routing: For integration into DistributedOrderSystem via GatewayBff

Direct Service: For external projects with direct communication to ChatbotService

<!-- Include the widget in your HTML --> <script src="/api/chatwidget/chat-widget.min.js"></script> <script> // Configuration for BFF routing window.chatWidgetConfig = { useBffRouting: true, bffBaseUrl: '/api/gateway/chat', theme: 'light', primaryColor: '#4299e1', position: 'bottom-right', autoOpen: false, botName: 'AI Assistant', welcomeMessage: 'Hi! How can I help you today?' }; // The widget initializes itself automatically </script>

🔧 Programmatic initialization

// For advanced control const widget = new DistributedChatWidget({ useBffRouting: false, // Direct mode chatbotServiceUrl: 'https://your-service.com/api/chat', theme: 'dark', primaryColor: '#9f7aea', jwtToken: 'your-auth-token' }); // Controlli programmatici widget.show(); widget.hide(); widget.updateConfig({ theme: 'light' });
